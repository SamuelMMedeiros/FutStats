# Referência pública BetoIA

A URL `https://www.betoia.app/sport` redireciona para uma tela de login, portanto os recursos internos de esporte não puderam ser inspecionados sem autenticação do usuário. Não foi executada tentativa de login nem de aposta.

A análise de interface pública confirma uma direção visual de produto de prognósticos: fundo escuro, forte uso de verde como acento de ação/êxito, foco em navegação por categoria e linguagem orientada a palpites. A implementação do FutStats deve usar somente padrões gerais de UX como abas de mercados, comparação de odds, seleção de partidas e geração de bilhete, sem copiar textos, identidade, ativos ou lógica proprietária.

A tela pública não é evidência suficiente para afirmar quais endpoints, mercados ou regras internas o BetoIA usa. Os requisitos técnicos do FutStats devem continuar baseados nas APIs configuradas e nos dados efetivamente retornados por elas.
